# TK观察 Logo 资产

`tk-observer-mark.svg` 是主应用图标；`tk-observer-mark-symbol.svg` 是透明背景符号；`tk-observer-mark-mono.svg` 用于单色印刷和压印。

## 使用规则

- 主标最小显示尺寸为 16px，32px 以下不附加中文或英文文字。
- 图形四周至少保留画布宽度 14% 的安全区域。
- 不旋转、不拉伸、不改变 TK 几何路径，不添加阴影或描边。
- 深色背景使用主标或透明符号；浅色背景优先使用主标。
- 商业文件使用 SVG；需要位图时使用 `design-assets/tk-observer-logo/` 下的 1024px PNG。

## 设计来源

现有横版 Logo 提供品牌绿色、`TK` 和观察语义。新版参考 GitHub 开源项目 Lucide、OpenObserve、SigNoz 和 Plausible Analytics 的单主体、小尺寸识别与有限色板原则，所有最终 SVG 路径均为本项目原创重绘，不复制这些项目的商标。
