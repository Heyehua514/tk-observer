# 项目错题本与经验库 (LESSONS)

> 规则说明：每次任务中踩坑、类型检查报错或重构事故，在此追加一条具体规避规则。保持精简，定期合并。

1. **后端优先**：涉及全栈功能时，先写 Supabase Migration 并校验，严禁先写前端假数据导致返工。
2. **三击熔断**：任何单一编译/运行错误连续尝试 3 次未果，立即记录现场并挂起，转入下一任务，严禁死磕。
3. **确定性脚本**：涉及数据处理与迁移，写独立脚本跑完即走，严禁在模型上下文手工处理大批量数据。
4. **跨币种一致性**：涉及多国家/多币种定价与成本时，必须显式定义采购成本币种、销售币种与基准汇率转换函数，严禁在未换算汇率的情况下直接做减法计算毛利率与利润。
