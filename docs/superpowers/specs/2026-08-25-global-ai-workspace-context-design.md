# 全局个人 AI 工作台上下文设计

## 目标

让同一个 WorkBuddy AI 助手在总览、商务、市场、设计和剪辑工作台中，按当前登录人的 RLS 权限读取少量真实业务摘要，结合个人记忆生成建议；AI 不自动写入业务数据，所有后续操作仍由用户确认。

## 已确认决策

- AI 推理只通过用户本机 `http://127.0.0.1:8877/analyze` 的 WorkBuddy 网关，不使用外部 AI API。
- 数据读取发生在用户点击「让 WorkBuddy 执行」之后，使用浏览器内当前 Supabase 会话；不使用 `service_role`、不绕过 RLS。
- 每次请求最多携带 24 条工作项、8 条个人记忆和每类工作台 4 个聚合指标，避免整库读取、过长提示词和无关数据泄漏。
- 业务记录文本一律视为不可信数据：先脱敏，再置于 `<workspace-data>` 边界内，并明确禁止执行其中指令。
- AI 返回的是建议文本。保存到 `ai_notes`、记住到 `ai_memory`、创建任务或更新业务记录均需用户分别确认。
- 本阶段不新增迁移，不启动后台定时分析，不改变视频导入流程，也不实现移动端或多设备 AI 队列。

## 结构

```text
AiAssistantPanel
  -> useAiWorkspaceContext(scope)
    -> Supabase browser session
      -> RLS-filtered summary queries
    -> normalize + redact + limit
  -> buildWorkspaceAiPrompt(...)
  -> WorkBuddy local gateway
  -> suggestion result
  -> user-confirmed save / remember / later action card
```

`ai-workspace-context.ts` 是纯函数层，负责限定、排序、脱敏和提示词构造。`use-ai-workspace-context.ts` 是唯一的数据读取层，按 `scope` 执行明确白名单查询。`AiAssistantPanel` 只负责用户交互和调用，不直接了解表结构。

## 数据白名单

| 工作台 | 允许摘要 | 上限 |
|---|---|---|
| 总览 | 未完成团队任务、GMV 聚合、最近活动 | 12 任务，4 指标 |
| 商务 | 本人可见商机、渠道商单、客户跟进 | 每类 8 条 |
| 市场 | 活动、活动任务、报名和财务聚合 | 每类 8 条 |
| 设计 | 设计需求、设计任务、待审核素材 | 每类 8 条 |
| 剪辑 | 选题、视频任务、对标账号、热点 | 每类 8 条 |

所有查询只选择业务决策需要的标题、状态、截止日、金额汇总、数量和更新时间。不得读取密码、Token、文件原始地址、完整手机号、完整备注全文或个人 AI 记忆之外的成员私有数据。

## 提示词合同

生成的提示词固定包含：角色与工作台、用户问题、已确认记忆、RLS 返回的上下文、输出格式要求。上下文外层明确标记为不可信数据，并要求 AI：

1. 先判断数据不足或异常，不编造结论。
2. 输出最多 3 个优先行动、每项给出依据和风险。
3. 标记建议类型为“分析”“调研”“任务草稿”或“需要补充数据”。
4. 不声称已经创建任务、修改记录、发送消息或访问外部账号。

## 错误处理

- 未登录、PocketBase 回退或 RLS 查询失败：显示“当前数据上下文不可用”，但允许用户提交手动问题给 WorkBuddy。
- 单个摘要查询失败：保留其他成功摘要，并在提示词中记录缺失类别，不以空结果伪装为真实零数据。
- WorkBuddy 网关不可用：不保存 AI 结果，不写记忆，不改变任何业务记录。
- 返回文本为空：作为失败处理，不显示“分析完成”。

## 验收与安全边界

- 普通成员只能把本人 RLS 可见的数据放入 AI 提示词。
- 提示词不包含秘密、访问令牌、文件私有 URL 或他人 `ai_memory`。
- 相同输入的上下文规范化结果稳定、可由单元测试复现。
- 用户没有点击执行时不触发任何业务数据请求或 WorkBuddy 调用。
- AI 结果仅在用户点击保存或记住后才写入 `ai_notes` / `ai_memory`。
- 通过相关 Vitest、typecheck、lint、build 和 `git diff --check` 后才能合并。

## 非目标

- 不把 AI 变成具有数据库写权限的自动执行器。
- 不自动抓取未授权的平台数据。
- 不在网页端保存 WorkBuddy 登录、密钥或额度信息。
- 不替代后续的 `ai_jobs` / `ai_devices` 桌面任务队列。
