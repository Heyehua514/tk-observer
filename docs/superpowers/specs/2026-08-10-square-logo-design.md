# TK观察正方形 Logo 设计

## 目标

将现有横版深绿色字标重绘为一个可用于桌面应用、登录页、侧边栏和 favicon 的正方形标志。新版第一眼必须表达“观察”，第二眼可以识别 `TK`，不依赖中文小字。

## 设计

唯一方向命名为“TK观察之眼”。画布为 `1024 x 1024`，深森林绿圆角方形承载主体；中央使用高对比度眼形观察窗，瞳孔内以无字体依赖的几何路径合并 `T` 与 `K`；右上只保留一个电光蓝信号点。图形不使用细线、渐变、阴影或文字节点，确保 16px 仍保留眼形轮廓。

## 色彩

- 深森林绿 `#063F37`：正方形底色，延续现有深绿色品牌资产。
- 雾白 `#F1FFFB`：观察窗主体。
- 海盐绿 `#16C3A5`：TK 几何字母和增长语义。
- 电光蓝 `#6D9CFF`：唯一信号点，与工作台主操作色呼应。

## 开源参考

参考 GitHub 上 [Lucide](https://github.com/lucide-icons/lucide)、[OpenObserve](https://github.com/openobserve/openobserve)、[SigNoz](https://github.com/SigNoz/signoz) 和 [Plausible Analytics](https://github.com/plausible/analytics) 的单主体、小尺寸识别和有限色板原则。最终路径为项目原创重绘，不复制这些项目的商标或 Logo。

Lucide 采用 ISC License；本项目仅借鉴 `Eye` / `ScanEye` 的通用观察语义，交付目录保留来源说明。

## 交付

- 主标 SVG：透明画布中的完整正方形应用图标。
- 单色 SVG：用于印刷、压印和单色环境。
- 透明符号 SVG：移除方形底板，用于毛玻璃登录页。
- 1024px PNG：主标、单色和透明符号各一份。
- 预览图：同时展示白底、深色侧边栏、毛玻璃登录页和 32px 小图标。

## 验收

- 所有 SVG 使用 `viewBox="0 0 1024 1024"`，无 `<text>`、外链、滤镜和字体依赖。
- 主标在 16px、32px、64px 和 1024px 均保持中心主体可辨。
- 主标颜色不超过四个，单色版仅一个前景色。
- PNG 精确为 `1024 x 1024`，透明版保留 alpha 通道。
- 不修改登录逻辑、认证流程或现有业务组件。
