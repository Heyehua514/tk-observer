# 商机预计金额人民币输入设计

## 目标

商务工作台新增商机时，预计金额以人民币元输入和展示。输入 `10000` 后，商机卡片显示 `¥10,000.00`，PocketBase 仍保存 `1000000` 分。

## 范围

- 将新增商机表单标签改为“预计金额（人民币/元）”。
- 表单允许输入最多两位小数的人民币金额。
- 提交前将人民币元转换为整数分。
- 商机卡片使用 `zh-CN` 和 `CNY` 货币格式展示。
- 不修改 PocketBase collection、migration 或已有数据。
- 不调整其他商务模块的金额输入、图标或视觉样式。

## 数据流

1. 用户在表单输入人民币元字符串。
2. 独立金额转换函数校验格式并转换为整数分。
3. 创建商机请求只向 PocketBase 提交整数分。
4. 查询返回的分值通过统一人民币格式化函数显示。

## 边界与错误

- 空值、负数、非数字和超过两位小数的输入无效。
- `0` 允许输入，但保存按钮仅在金额有效时启用。
- 转换采用字符串拆分，不使用浮点乘法，避免 `0.1 * 100` 一类精度问题。

## 验证

- Gate tests 覆盖整数、两位小数、无效输入和人民币格式化。
- 组件测试验证用户输入 `10000` 时，创建请求收到 `1000000`。
- 运行 `pnpm typecheck`、`pnpm lint`、前端测试和 `pnpm build`。
