## 换设备恢复

1. 克隆 `https://github.com/Heyehua514/tk-observer.git`，进入项目目录。
2. 安装 Node 20+、pnpm 11+、Rust 和 Tauri 2 所需系统依赖。
3. 执行 `pnpm install --frozen-lockfile`。
4. 在本机创建 `.env`，配置 Supabase URL 和 anon key；不要提交 `.env`、密码、Token、`hosts` 或 service role key。
5. 执行 `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build`。
6. 需要桌面开发时执行 `pnpm desktop:dev`；发布前使用 GitHub Actions Variables/Secrets，不在本机保存发布秘密。
7. WorkBuddy 需要在新设备重新登录本机客户端；首次使用前确认本机网关健康检查和权限提示。

## 安全边界

- 不读取、不提交、不复制密码文件、Token、二维码、微信登录凭据、设备序列号或 `hosts`。
- AI 只读取当前用户有权限的数据，并在用户主动点击后分析；不会自动修改业务数据。
- 任何真实生产变更先完成备份、权限确认和回滚演练。
