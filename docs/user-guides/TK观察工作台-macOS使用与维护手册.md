# TK观察工作台 macOS 使用与维护手册

> 适用平台：macOS Apple Silicon（当前已验证）
>
> 当前发布：v0.1.9
>
> 文档用途：内部团队使用
>
> 更新日期：2026-08-28

## 先看结论

TK观察工作台是一个面向 TikTok Shop 跨境电商团队的多角色协作系统。macOS 客户端是 Tauri 2 桌面壳，业务数据默认来自 Supabase；浏览器端和 Windows、手机端共用同一套线上数据。

> 版本口径：本手册生成时仓库 main 和最新标签实际为 v0.1.9；PRD 交接章节中的 v0.1.8 属于历史记录，下载和验收以 v0.1.9 为准。

本手册把能力分成三类：

- **现在可直接使用**：登录、五大工作台、搜索、通知、团队日历、CSV 导入导出、文件上传、AI 记录和大部分业务闭环。
- **需要外部配置或授权**：WorkBuddy 本机 AI、真实微信视频号采集、飞书 OAuth、生产 Supabase 数据和 Apple 签名。
- **规划中**：每日自动联网热点搜索、平台发布回填、文件版本对比、公开分发自动更新等。

本手册不包含密码、Token、二维码、service role key、hosts 或任何本地测试凭据。

## 2. 安装与首次启动

1. 打开 DMG 下载地址，确认文件名为 TK_0.1.9_darwin_aarch64.dmg。
2. 双击 DMG，把 TK观察工作台拖到 Applications。
3. 从 Applications 启动。首次启动若 macOS 提示无法验证开发者，右键应用选择“打开”，或在“系统设置 > 隐私与安全性”中允许本次打开。当前安装包未配置 Apple Developer ID 公证。
4. 在登录页输入管理员分配的公司账号。不要在浏览器、聊天记录或仓库保存密码。
5. 登录后会按角色进入默认工作台。先打开“系统设置”，确认客户端更新区域和数据服务状态。
6. 若要使用 AI，先在本机登录 WorkBuddy，再确认本机网关健康检查可用。

### 兼容范围

- 当前发布资产为 Apple Silicon（aarch64）。Intel Mac 安装包没有在本轮交付中验证。
- 客户端不内置独立业务数据库；网络可用时从 Supabase 读取数据。
- 关闭应用不会把密码写入磁盘；会话只保存在当前窗口的 sessionStorage。

## 4. 功能使用教程

### 4.1 全局能力

- **全局搜索**：在顶部输入关键词，可按达人、公司、商品、视频和客户分组查看结果。搜索有防抖，结果会按角色隐藏无权访问的数据。
- **通知中心**：顶部铃铛显示未读数；可进入全量通知列表，按全部、未读、到期、审核、跟进和成交筛选，也可以单条或全部标记已读。
- **团队日历**：总览中的日历聚合活动、活动任务、设计需求、朋友圈计划和渠道商单排期；有具体时刻时同时展示北京时间和活动城市时间。
- **实时刷新**：达人、设计素材、通知、关联视频和主要 Supabase 业务表通过 Realtime 触发查询刷新，在线成员不需要反复手动刷新。
- **系统设置**：查看数据服务、客户端更新、通知偏好和服务器回退设置。PocketBase 只在明确配置回退时使用。

### 4.2 总览工作台

1. 查看 GMV 近 7 天、近 30 天或全部趋势。
2. 查看团队动态、待办任务、签约达人、出片数和成员进度。
3. 查看近期活动和活动阶段分布。
4. 打开团队记忆，查看日报、周报、截止提醒和失败案例。
5. 对需要处理的设计审批、商机成交通知和到期事项，从通知或卡片进入原页面。

GMV 金额以人民币元展示，数据库按最小货币单位保存。空数据时显示引导状态，不代表系统自动生成了经营数据。

### 4.3 商务工作台

**达人管理**

- 新增、查看、编辑、删除达人。
- 按昵称、主页、对接人搜索，按地区和合作状态筛选排序。
- 分页、批量更新合作状态、批量删除。
- 标记“可商务合作”，维护报价和商务备注。
- 从达人详情查看关联视频。

**公司与客户**

- 新增、编辑、删除客户和供应商。
- 维护联系人、电话、微信、行业、来源、重要度和备注。
- 按行业、来源、重要度筛选，按名称和对接人搜索。
- 在客户详情查看关联商机和渠道商单，并跳转到对应记录。

**商机 Pipeline**

- 六个阶段：初步接洽、方案报价、商务谈判、合同签署、已成交、已流失。
- 拖拽卡片推进阶段，点击卡片打开详情。
- 维护预计金额、预计成交日期、跟进备注和流失原因。
- 切换到“已流失”时必须填写原因；成交会给负责人生成通知并留下审计记录。

**渠道商单**

- 新增、更新状态、删除商单。
- 关联客户和可商务合作达人。
- 维护平台、内容类型、人民币金额、佣金、预计发布日期和播放量。
- 按状态、平台、内容类型筛选，按标题、客户和达人搜索。
- 标记取消时填写取消原因，已发布记录不应被当作新的商单修改。

**朋友圈运营**

- 新增计划，维护发布日期、内容、目标受众、预期转化和实际结果。
- 在日历视图和列表视图之间切换。
- 复盘后可关联转化商机，系统会在商机备注留下来源记录，重复提交不会重复追加。

**公众号分析**

- 查看 TK观察及对标账号文章。
- 按关键词和账号筛选，查看文章总数、爆款数和本月新增。
- 录入阅读、在看、转发和分析笔记。
- 爆款状态由服务端按同账号平均阅读量规则计算，客户端不能手工伪造。

### 4.4 市场工作台

**活动管理**

- 新增、搜索和软删除活动。
- 活动详情包含活动概览、任务看板、招商跟进、报名管理、财务复盘和进度总览六个 Tab。
- 新建活动自动生成 P0-P4 标准阶段和财务模板。
- 任务支持待处理、进行中、已完成三列拖拽，进度总览聚合任务、报名、招商和物料完成度。

**场地资源库**

- 新增和编辑场地，最多上传 10 张照片。
- 按名称、标签、城市、类型和人数筛选。
- 使用活动城市、人数和类型快速匹配场地。
- 查看照片轮播、踩点记录和历史活动。

**文案模板与物料**

- 新增模板，使用活动变量预览并记录套用次数。
- 新增物料并上传文件，维护物料类型、设计状态、活动和设计师关联。

**财务复盘**

- 录入收入和支出，金额以人民币元输入。
- 查看收入、支出、利润和利润率。
- 新建活动自动带出赞助、票务、场地、布置、餐饮、印刷和差旅模板。
- 导出 CSV 明细或 Markdown 复盘报告。

**选品库**

- 查看商品和毛利模型，支持搜索和筛选。
- 选品库当前重点是数据展示和经营判断；真实供应链或广告数据需要人工导入或后续数据源接入。

### 4.5 设计工作台

- 上传设计素材并提交审核。
- boss 通过或驳回；驳回必须填写理由，结果会生成通知。
- 新建和接收设计需求，维护“待接单 > 制作中 > 已交付”状态。
- 在需求详情维护尺寸、场景、文案、格式、参考链接、视觉参考和交付记录。
- 使用四列设计任务看板：待设计、进行中、待审核、已完成。
- 交付记录可以关联已审批素材，保存导出规格和检查结果。
- 品牌规范页提供当前规范参考；规范数据化和文件版本对比仍在规划。

### 4.6 剪辑工作台

- 维护微信视频号选题，支持三个预置账号和视频类型。
- 按关键词、账号、类型、日期、标签和爆款状态筛选。
- 下载 CSV 模板、批量导入选题、导出筛选结果、查看导入历史。
- 查看核心指标、账号对比、类型对比和爆款特征分析视图。
- 维护对标账号、对标视频、爆款原因、可借鉴点和风格分析。
- 录入热点话题，解析后人工确认并一键预填为选题。
- 视频任务、成片归档和发布排期页面已有基础入口；完整的视频任务 CRUD、成片上传预览和平台发布闭环仍需继续完善。

### 4.7 每日情报中心

- 在“情报中心”新增情报，填写标题、摘要、来源类型、来源名称、原文链接、采集时间、地区、语言、主题、热度和可信度。
- 按关键词、工作台和状态筛选。
- 标记已读、收藏和安全打开原文。
- “转为任务”只记录人工确认意图，不会自动创建业务任务。

当前情报中心支持人工录入和 CSV 导入。它还没有每日自动联网搜索 RSS、新闻站点或未授权平台。

## 5. AI 助手与 WorkBuddy

### 5.1 使用方式

1. 在带 AI 面板的总览或剪辑页面点击“AI 助手”或“视频 AI 分析”。
2. 阅读授权提示。实际分析会消耗当前 Mac 上 WorkBuddy 的额度。
3. 确认后，系统按当前账号权限读取上下文；视频分析默认读取最近 50 条选题。
4. 查看标题规律、发布时间、内容偏好和总结等结构化结果。
5. 在 AI 记录库中选择“采用”或“忽略”，由成员人工决定是否执行。

AI 只返回建议，不自动改任务、负责人、金额、阶段、截止日期或其他业务数据。AI 记录的采用、忽略和删除都有权限限制与审计。

### 5.2 本机前置条件

- WorkBuddy 桌面端已安装并登录。
- 本机网关监听 127.0.0.1:8877。
- 可在浏览器访问 http://127.0.0.1:8877/health 检查健康状态。
- 桌面上已有“启动WorkBuddy网关.command”时，可双击启动；不要把网关绑定到公网地址。

网关默认使用本机 WorkBuddy CodeBuddy CLI。CLI 缺失、未登录、额度不足、超时或输出校验失败时，页面会显示稳定错误，并保留原业务数据不变。

## 6. 数据来源、同步和离线边界

- 默认数据源是 Supabase Auth、Postgres、RLS、Storage、Realtime 和自动化。
- PocketBase 仅作为显式回退，不是新功能的默认数据源。
- macOS、Windows、手机端共用同一 Supabase 项目；在一端新增或更新的数据会按权限同步到其他端。
- 图片、视频、设计稿和财务凭证使用私有 Storage，访问链接受权限控制。
- 手机离线时只能看到已缓存的页面外壳，不能保证业务数据读写；恢复网络后刷新页面。
- 会话只在当前窗口保存，关闭客户端后可能需要重新登录。

## 7. 更新客户端

### 客户端内更新

1. 打开“系统设置 > 客户端更新”。
2. 点击“检查更新”。
3. 发现新版本后确认下载、安装并重启。
4. 重启后重新登录并检查当前版本和主要页面。

更新功能依赖签名清单和 Release 资产。当前清单地址是：

https://github.com/Heyehua514/tk-observer/releases/latest/download/latest.json

如果页面显示“检查更新失败”或更新服务不可用：

1. 先确认网络和 GitHub Release 访问权限。
2. 打开 v0.1.9 发布页，手动下载新的 DMG。
3. 退出旧客户端，把新应用拖入 Applications 并替换。
4. 重新登录。业务数据在 Supabase，不因替换应用而删除。

不要下载来路不明的安装包，不要手动替换应用内签名文件，也不要把 Token 作为更新凭据写进应用。

## 8. 常见问题

### 8.1 macOS 阻止打开

当前包未做 Developer ID 公证。右键“打开”一次，或在“系统设置 > 隐私与安全性”允许。若文件来源不是本手册的 Release 地址，停止安装并联系维护者。

### 8.2 登录后看不到数据

确认使用的是正确成员账号、网络可用且登录页地址为 https://tk-observer.pages.dev/login。若只有某个页面失败，刷新页面并查看通知中的重试入口；不要擅自改数据服务地址。

### 8.3 AI 助手提示网关不可用

确认 WorkBuddy 已登录、网关已启动、http://127.0.0.1:8877/health 可访问。手机或远程浏览器不能直接访问这台 Mac 的 127.0.0.1。Windows 端还需要单独适配 Windows WorkBuddy CLI。

### 8.4 情报中心没有自动热点

这是当前产品边界，不是故障。现在需要人工录入或 CSV 导入；自动 RSS/新闻搜索列在后续计划。

### 8.5 底部版本文字与安装包不一致

应用侧边栏仍可能显示旧的静态文字“TK观察 · v0.9.6”。实际发布版本以 Release 标签、安装包文件名和系统设置中的客户端版本为准。

## 9. 后续计划

以下项目已经记录在 PRD，但不应当当作当前已交付能力：

- 每日自动搜索行业热点，接入经过授权的 RSS、新闻源或数据供应商。

- Windows WorkBuddy CLI 适配、手机端远程 AI 网关和更完整的 PWA 离线能力。
- Apple Developer ID 签名、公证和面向未登录用户的公开自动更新分发。

## 10. 换设备维护

换到另一台 Mac 时：

1. 克隆仓库：
   https://github.com/Heyehua514/tk-observer.git
2. 安装 Node.js 20+、pnpm 11+、Rust stable 和 Tauri 2 依赖。
3. 进入项目后执行：
   pnpm install --frozen-lockfile
4. 在本机创建 .env，只填 Supabase URL 和 anon key，不提交该文件。
5. 运行基础检查：
   pnpm typecheck
   pnpm lint
   pnpm test
   pnpm build
6. 需要桌面开发时运行：
   pnpm desktop:dev
7. 需要 WorkBuddy AI 时，在新设备重新登录 WorkBuddy 并确认本机网关健康检查。
8. 不复制密码文件、Token、hosts、二维码、设备凭据或 service role key。
