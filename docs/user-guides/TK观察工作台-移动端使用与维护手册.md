# TK观察工作台 移动端使用与维护手册

> 适用平台：iPhone、iPad、Android 手机和平板的现代浏览器
>
> 当前线上入口：网页/PWA
>
> 文档用途：内部团队使用
>
> 更新日期：2026-08-28

## 先看结论

移动端不是独立的 APK 或 IPA。手机直接打开线上网页即可使用，发布新版本后刷新页面就能获得最新前端。手机、macOS 和 Windows 共用同一个 Supabase 项目，因此同一账号有权限的数据会同步。

> 版本口径：本手册生成时仓库 main 和最新标签实际为 v0.1.9；PRD 交接章节中的 v0.1.8 属于历史记录，网页端以当前线上构建为准。

手机端能力状态：

- **现在可直接使用**：登录、角色工作台、搜索、通知、日历、业务查看和录入、CSV 小批量导入、文件预览、AI 记录查看和人工决策。
- **需要外部条件**：真实平台数据、飞书 OAuth、生产账号和文件权限。
- **当前限制**：手机不能直接访问桌面设备的 127.0.0.1 WorkBuddy 网关；每日自动联网热点和微信视频号自动采集尚未上线。

本手册不包含密码、Token、二维码、hosts 或本地测试凭据。

## 2. 首次使用流程

1. 在手机浏览器地址栏粘贴 https://tk-observer.pages.dev/login。
2. 等待登录页加载完成，确认地址栏是 HTTPS 且域名正确。
3. 输入管理员分配的公司账号并登录。
4. 登录后按角色进入总览、商务、市场、设计或剪辑工作台。
5. 首次使用可通过浏览器菜单选择“添加到主屏幕”或“安装应用”。这只是网页快捷方式，不是原生安装包。
6. 退出浏览器或清除站点数据后可能需要重新登录。

### 推荐浏览器设置

- 允许 JavaScript、Cookie/站点存储和文件选择。
- 使用稳定网络；上传图片、视频或 CSV 时不要锁屏。
- 不在公共设备勾选保存密码。
- 遇到白屏先刷新，不要重复提交同一个表单。

## 3. 角色与页面

| 角色     | 默认页面 | 适合在手机完成的工作                     |
| -------- | -------- | ---------------------------------------- |
| boss     | 总览     | 看经营指标、审批、通知、团队进度和日历   |
| business | 商务     | 查客户/达人、更新商机、查看商单和朋友圈  |
| market   | 市场     | 看活动、任务、招商、报名、场地和财务     |
| design   | 设计     | 看审核、接需求、更新任务、查看参考和交付 |
| editing  | 剪辑     | 查选题、导入小批量 CSV、看调研和分析结果 |

权限由 Supabase RLS 决定。手机端看不到某条记录通常是权限或筛选结果，不要通过改 URL 访问其他角色数据。

## 4. 移动端功能教程

### 4.1 搜索、通知和日历

- 点顶部搜索框，输入达人、公司、商品、视频或客户关键词。
- 点铃铛查看未读通知，可按未读、到期、审核、跟进和成交筛选。
- 在总览打开团队日历，查看活动、任务、设计需求、朋友圈计划和渠道商单。
- 数据更新后页面会按 Realtime 失效相关查询；网络不稳定时下拉刷新。

### 4.2 总览工作台

- 切换 GMV 近 7 天、近 30 天或全部。
- 查看待办、团队动态、签约达人、出片和成员进度。
- 从通知进入审批、成交或到期事项。
- 查看日报、周报、失败案例和 AI 记录（按角色权限显示）。

### 4.3 商务工作台

- 达人：搜索、筛选、查看详情、更新可商务合作标记和备注。
- 客户：新增或编辑联系人、行业、来源、重要度和备注；查看关联商机与商单。
- 商机：在六阶段 Pipeline 中查看或更新阶段、预计成交日期和跟进备注；已流失必须填原因。
- 商单：选择可商务合作达人，维护平台、内容类型、金额、佣金和预计发布日期。
- 朋友圈：在日历或列表中维护计划，复盘后关联转化商机。
- 公众号：筛选文章和对标账号，查看阅读、在看、转发和分析笔记。

手机屏幕较窄时，表格会横向滚动；金额以人民币元展示。

### 4.4 市场工作台

- 活动详情包含概览、任务看板、招商、报名、财务和进度六个 Tab。
- 小屏幕上拖拽任务时先长按卡片，再移动到目标列；拖拽失败可打开任务详情更新状态。
- 场地支持名称、标签、城市、类型和人数筛选，详情可切换照片。
- 模板支持变量预览；物料可按权限上传和预览。
- 财务支持收入/支出录入、利润查看和 CSV/Markdown 导出。大文件导出建议在桌面端完成。

### 4.5 设计工作台

- 查看待审核素材和通知。
- 设计角色可接收需求、维护制作状态、添加视觉参考和交付记录。
- boss/business 可查看审批和交付结果；驳回时填写具体理由。
- 设计任务看板支持待设计、进行中、待审核、已完成。

### 4.6 剪辑工作台

- 查看和筛选三个预置账号的选题。
- 下载 CSV 模板，使用手机文件管理器选择小批量 CSV 导入。
- 查看导入历史、核心指标、账号对比、类型对比和爆款特征。
- 查看对标视频、热点话题和风格分析；热点解析后必须人工确认。
- 视频任务、成片上传和平台发布流程仍有未完成部分，不要把页面入口当作完整发布能力。

### 4.7 情报中心

- 手动新增情报，填写标题、摘要、来源和原文链接。
- 使用 CSV 批量导入可验证的行业信息。
- 按关键词、工作台和状态筛选，标记已读或收藏。
- 打开外部链接前先确认来源和域名。

情报中心当前没有每日自动联网搜索。RSS、新闻源和授权数据源接入属于后续开发。

## 5. AI 助手、数据分析和手机限制

### 5.1 手机可以做什么

- 查看已有 AI 分析结果和 AI 记录。
- 对自己的 AI 记录选择“采用”或“忽略”。
- 阅读与当前工作台相关的建议、摘要和历史。
- 继续录入业务数据，再在有 WorkBuddy 的桌面端发起分析。

### 5.2 手机暂不能直接做什么

主动 AI 分析默认通过安装在桌面设备上的 WorkBuddy 和本机网关完成：

http://127.0.0.1:8877/analyze

手机上的 127.0.0.1 指向手机本身，不是办公室的 Mac 或 Windows。因此手机直接点分析可能提示网关不可用。不要把桌面网关改成公网地址，也不要把 WorkBuddy 或 GitHub Token 填入手机页面。后续会在具备安全认证、HTTPS 和权限隔离后再考虑远程 AI。

AI 每次都需要用户主动确认，会消耗 WorkBuddy 额度；结果需要人工确认，不会自动修改任务、金额、负责人、阶段或截止日期。

## 6. 数据同步和离线边界

- 手机、Windows 和 macOS 共用 Supabase Auth、Postgres、RLS、Storage 和 Realtime。
- 同一账号在手机录入的客户、活动、选题或备注，会在其他端按权限出现。
- 文件预览使用私有 Storage 签名链接；权限变化后旧链接可能失效。
- 离线时可以看到登录页外壳和部分缓存资源，但不能保证业务数据读写。
- 提交失败时先看页面错误提示和重试按钮，确认没有成功后再重新提交，避免重复记录。
- 浏览器清除站点数据会清除会话，需要再次登录。

## 7. 手机端更新

移动端不需要下载新安装包。维护者发布新 Web 构建后：

1. 关闭当前工作台页面。
2. 重新打开 https://tk-observer.pages.dev/login。
3. 若仍显示旧页面，在浏览器下拉刷新；必要时清除该站点缓存后重新登录。
4. 检查“系统设置 > 客户端更新”显示“网页端发布新版本后刷新页面即可获取更新”。

手机端没有独立版本号资产，也不需要运行桌面 updater。桌面端更新清单只供 macOS/Windows 客户端使用：

https://github.com/Heyehua514/tk-observer/releases/latest/download/latest.json

## 8. 常见问题

### 8.1 手机打不开链接

确认复制的是完整地址 https://tk-observer.pages.dev/login，并使用系统 Safari、Chrome、Edge 或 Firefox。不要从聊天软件内置浏览器直接打开；先复制到地址栏。

### 8.2 Android 一定要用 Google 吗

不需要。Android 只需要一个支持现代 JavaScript 和站点存储的浏览器。Chrome 不是唯一选择，Edge、Firefox 和多数厂商浏览器都可以。

### 8.3 登录后反复回到登录页

检查浏览器是否禁用了 Cookie/站点存储，是否使用隐私模式，以及网络是否在切换。关闭隐私模式、允许站点存储后重新登录。

### 8.4 页面显示空数据

先清除关键词和筛选条件，再检查账号角色和网络。空态、筛选后无结果和加载失败是三种不同状态；加载失败时使用“重试”。

### 8.5 CSV 导入失败

使用系统文件选择器重新选择 UTF-8 CSV，确认必需列和日期格式正确。标题加发布日期重复时系统会跳过或提示，不要连续点击提交。

### 8.6 图片或视频打不开

确认当前账号有权限、网络稳定且链接未过期。私有 Storage 不支持把 URL 复制给无权限成员长期访问。

### 8.7 AI 助手没有反应

这通常是桌面 WorkBuddy 网关问题，不是手机浏览器问题。到已安装 WorkBuddy 的 Mac/Windows 设备检查登录和 http://127.0.0.1:8877/health；手机端不能自行修复该本机服务。

## 10. 换设备维护

换手机不需要迁移数据库：

1. 在新手机打开 https://tk-observer.pages.dev/login。
2. 使用同一公司账号登录。
3. 确认角色页面、通知和数据与旧手机一致。
4. 如需主屏图标，重新执行“添加到主屏幕”。

换电脑维护代码时：

1. 克隆 https://github.com/Heyehua514/tk-observer.git。
2. 安装 Node.js 20+、pnpm 11+、Rust/Tauri 2 和对应平台构建工具。
3. 执行 pnpm install --frozen-lockfile、pnpm typecheck、pnpm lint、pnpm test、pnpm build。
4. 在新设备重新登录 WorkBuddy；不要复制密码文件、Token、hosts、二维码、设备凭据或 service role key。
