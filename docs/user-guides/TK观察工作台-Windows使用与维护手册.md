# TK观察工作台 Windows 使用与维护手册

> 适用平台：Windows x64（Intel/AMD）
>
> 当前发布：v0.1.9
>
> 文档用途：内部团队使用
>
> 更新日期：2026-08-28

## 先看结论

Windows 客户端和 macOS 客户端使用同一份前端与 Supabase 数据。Windows 安装包是 Tauri 2 NSIS 安装程序，当前按 x64 构建；手机端不需要安装 Windows 包，直接访问网页。

> 版本口径：本手册生成时仓库 main 和最新标签实际为 v0.1.9；PRD 交接章节中的 v0.1.8 属于历史记录，下载和验收以 v0.1.9 为准。

能力状态：

- **现在可直接使用**：五大工作台、登录、搜索、通知、实时同步、CSV、文件上传、业务看板和 AI 记录。
- **需要外部条件**：本机 WorkBuddy AI、真实微信视频号采集、飞书 OAuth、生产数据和代码签名。
- **规划中**：每日自动联网热点、平台发布回填、Windows WorkBuddy 完整适配、公开分发自动更新。

不在本手册保存密码、Token、二维码、hosts 或其他敏感凭据。

## 2. 安装与首次启动

1. 下载并确认文件名为 TK_0.1.9_windows_x64_setup.exe。
2. 双击安装程序，按向导完成安装。
3. Windows SmartScreen 若出现提示，先点“更多信息”，核对发布页和文件名，再选择运行。来源不明时不要放行。
4. 若系统提示缺少 WebView2，按提示安装 Microsoft Edge WebView2 Runtime，然后重新启动安装程序。
5. 启动 TK观察工作台，使用管理员分配的公司账号登录。
6. 登录后打开“系统设置”，确认客户端更新和数据服务状态。
7. 若使用 AI，先在同一台 Windows 电脑安装并登录可用的 WorkBuddy 客户端，再检查本机网关。

### 运行要求

- Windows x64，建议 Windows 10/11。
- Microsoft WebView2 Runtime。
- 网络访问 Supabase 和 Release 地址。
- 客户端不依赖本地 PocketBase 才能使用线上数据。

当前发布流水线已经生成 Windows x64 安装资产；具体 Windows 版本、杀毒软件和企业策略仍需在目标电脑人工验收。

## 3. 登录与角色

| 角色     | 默认入口 | 主要职责                                 |
| -------- | -------- | ---------------------------------------- |
| boss     | 总览     | 经营总览、审批、团队进度、活动监督       |
| business | 商务     | 客户、达人、商机、商单、朋友圈和招商协作 |
| market   | 市场     | 活动、场地、报名、招商、物料和财务复盘   |
| design   | 设计     | 素材、设计需求、任务看板、视觉参考和交付 |

角色权限由路由和 Supabase RLS 共同控制。不能通过修改 URL 或浏览器开发者工具绕过权限。

## 4. 功能使用教程

### 4.1 全局能力

- **全局搜索**：顶部搜索支持达人、公司、商品、视频和客户分组结果，按权限隐藏数据。
- **通知中心**：铃铛显示未读数；列表可按未读、到期、审核、跟进和成交筛选，可单条或全部已读。
- **团队日历**：总览日历聚合活动、任务、设计需求、朋友圈计划和渠道商单；有具体时刻时展示北京时间和活动城市时间。
- **实时同步**：在线页面通过 Supabase Realtime 失效相关查询，其他成员更新后列表会自动刷新。
- **系统设置**：查看数据服务、更新、通知偏好和显式 PocketBase 回退设置。

### 4.2 总览

1. 切换 GMV 近 7 天、近 30 天或全部。
2. 查看团队动态、待办、签约达人、出片和成员进度。
3. 打开近期活动、阶段分布、团队日历和团队记忆。
4. 从通知直接进入设计审批、成交或到期事项。

GMV 使用人民币元展示，空数据时不会填充假曲线。

### 4.3 商务

**达人**

- 新增、编辑、删除、搜索、筛选、排序、分页和批量状态更新。
- 标记可商务合作、维护报价和备注。
- 在详情查看关联视频。

**客户与公司**

- 维护联系人、电话、微信、行业、来源、重要度和备注。
- 按行业、来源、重要度筛选。
- 从详情跳转到关联商机和渠道商单。

**商机**

- 六阶段：初步接洽、方案报价、商务谈判、合同签署、已成交、已流失。
- 拖拽推进阶段，详情维护金额、预计成交日期、备注和流失原因。
- 已流失必须填写原因；成交会通知负责人并记录审计。

**渠道商单**

- 维护客户、可商务达人、平台、内容类型、人民币金额、佣金、预计发布日期和播放量。
- 支持状态、平台、内容类型筛选和关键词搜索。
- 取消时必须留下取消原因。

**朋友圈和公众号**

- 朋友圈支持日历/列表、状态流转、实际结果和商机复盘。
- 公众号支持文章、账号筛选、阅读/在看/转发、分析笔记和服务端爆款判定。

### 4.4 市场

**活动**

- 新建活动后自动生成 P0-P4 阶段和七类财务模板。
- 活动详情六个 Tab：概览、任务看板、招商、报名、财务和进度。
- 任务看板支持待处理、进行中、已完成拖拽。

**场地**

- 场地新增/编辑、最多 10 张照片、名称/标签/城市/类型/人数筛选。
- 按活动城市、人数和类型快速匹配。
- 查看照片、踩点和历史活动。

**模板、物料和财务**

- 模板变量预览和套用次数。
- 物料上传、类型、设计状态和活动关联。
- 财务收入/支出、利润率、CSV 和 Markdown 复盘导出。

**选品**

- 查看商品、搜索和毛利判断。
- 真实供应链、广告和转化数据要通过人工导入或授权数据源补齐。

### 4.5 设计

- 上传素材，提交审核，boss 通过或驳回。
- 驳回必须填写理由，并自动生成通知。
- 设计需求按待接单、制作中、已交付流转。
- 维护尺寸、场景、文案、格式、参考链接、视觉参考和交付记录。
- 使用待设计、进行中、待审核、已完成四列任务看板。

### 4.6 剪辑

- 选题 CRUD、三个预置账号、类型/日期/标签/爆款筛选。
- CSV 模板下载、批量导入、筛选结果导出和导入历史。
- 核心指标、账号对比、类型对比和爆款特征视图。
- 对标账号、对标视频、热点话题、风格分析和一键预填选题。
- 视频任务、成片归档和发布排期已有基础入口；完整 CRUD、上传预览和平台发布回填仍在后续范围。

### 4.7 情报中心

- 人工新增或 CSV 导入标题、摘要、来源、链接、时间、地区、语言、主题、热度和可信度。
- 按关键词、工作台、状态筛选，支持已读、收藏和安全打开来源。
- 转为任务需要人工确认，不会自动创建任务。

当前没有每日自动联网搜索行业热点；不能把手动导入记录当作平台实时抓取。

## 5. AI 助手与 WorkBuddy

### 5.1 主动分析流程

1. 打开总览或剪辑中的 AI 面板。
2. 阅读授权提示并确认会消耗本机 WorkBuddy 额度。
3. 系统只携带当前账号有权限的数据；视频分析默认读取最近 50 条选题。
4. 查看标题规律、发布时间、内容偏好和总结。
5. 在 AI 记录库人工选择采用或忽略。

AI 不能自动修改任务、负责人、金额、阶段、截止日期或其他业务字段。敏感备注会在送入本机 CLI 前做确定性脱敏。

### 5.2 Windows 限制

当前默认网关配置使用本机地址 http://127.0.0.1:8877。macOS 已验证 WorkBuddy CodeBuddy CLI 路径；Windows CLI 路径和 WorkBuddy 安装形态尚未完成正式适配，因此 Windows 上 AI 助手可能显示“网关不可用”。

若本机已有网关：

- 在浏览器打开 http://127.0.0.1:8877/health。
- 确认 WorkBuddy 已登录且额度可用。
- 不要把网关改成公网监听，也不要把账号 Token 填进页面。

手机访问网页时不能直接访问 Windows 的 127.0.0.1，远程 AI 网关属于后续安全方案。

## 6. 数据同步

- Windows、macOS 和手机共用 Supabase Auth、Postgres、RLS、Storage 和 Realtime。
- 一端新增客户、活动、选题或设计记录后，其他端在有权限的情况下可以看到。
- 文件位于私有 Storage，下载和预览需要当前账号权限。
- 关闭客户端后会话可能清除，需要重新登录。
- 离线只能保证登录页外壳等缓存内容，业务写入请在网络稳定时完成。

## 8. 常见问题

### 8.1 双击后没有窗口

检查 SmartScreen、杀毒软件隔离记录和 WebView2。确认是 x64 Windows，重新从本手册的 Release 地址下载并再次运行。

### 8.2 GitHub 打不开

安装包下载和 GitHub 页面访问是两件事。先尝试直接安装包地址；若公司网络拦截 GitHub，使用已批准的内部文件转发方式，并核对文件哈希。不要向客户端填入个人 Token。

### 8.3 更新一直失败

确认网络能访问 latest.json、版本清单与安装包架构一致。若仓库访问权限导致 404，直接手动下载新安装包。

### 8.4 登录成功但没有数据

确认账号、线上地址和网络；不要把 VITE_DATA_PROVIDER 改成 PocketBase。刷新后仍失败时记录页面错误提示和时间，交给维护者检查 Supabase 会话与 RLS。

### 8.5 AI 助手不可用

Windows WorkBuddy CLI 尚未完成与 macOS 相同的正式适配。先检查本机网关健康状态；若仍不可用，继续使用数据分析和 AI 记录库，不要反复输入凭据。

### 8.6 版本文字不一致

侧边栏可能还显示静态文字“TK观察 · v0.9.6”。实际版本以安装包文件名、Release 标签和客户端版本读取为准。

## 10. 换设备维护

在另一台 Windows 电脑维护代码：

1. 克隆仓库：
   https://github.com/Heyehua514/tk-observer.git
2. 安装 Node.js 20+、pnpm 11+、Rust stable、Tauri 2、Visual Studio C++ Build Tools 和 WebView2。
3. 执行：
   pnpm install --frozen-lockfile
4. 创建本机 .env，只写 Supabase URL 和 anon key，不提交。
5. 检查：
   pnpm typecheck
   pnpm lint
   pnpm test
   pnpm build
6. 桌面开发：
   pnpm desktop:dev
7. Windows 发布需要在 Windows runner 上执行对应的 Tauri NSIS 构建；发布秘密只放 GitHub Actions Secrets。
8. 不复制密码文件、Token、hosts、二维码、设备凭据或 service role key。
