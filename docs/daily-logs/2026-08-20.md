## 经验与反思

- pgTAP `plan()` 必须和实际断言数逐条匹配。本日两次发现计划数偏差，均在全量门禁前修正。
- RLS 策略不等于数据库权限。文档读取需要同时具备 `SELECT` 授权与 owner RLS；连接 token 表必须同时取消表级读取和 RLS 读取路径。
- 已应用 migration 不能回改。权限修正必须追加 `20260820000410_feishu_document_read_grants.sql`，不能修改已应用的 `20260820000400`。
- Edge Function 缺少 Deno 本地运行环境时，只完成可本地证实的数据层和前端契约，不把 OAuth 交换标记为可用。
