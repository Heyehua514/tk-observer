# 后续迭代建议清单

## P0：下一轮优先完成

1. 把客户/供应商管理按达人 CRUD 模板做完整，验证第二个模块复制成本。
2. 完成选品库 CRUD，并统一金额最小单位、币种和毛利率计算。
3. 完成微信视频号视频任务 CRUD 和成片归档上传、视频预览、文件类型及大小限制，并关联现有选题库。
4. 为全局搜索补齐“查看全部 N 条”结果页，并把列表筛选条件带到目标工作台。
5. 增加自动化权限测试：五角色路由矩阵、Collection 读写矩阵、退出缓存清理。
6. 为成员首次注册增加一次性邀请码或企业邮箱验证，避免公网环境下姓名被抢先绑定。
7. 增加通知与审批端到端测试，覆盖空驳回理由、越权审批、已读状态和 realtime 刷新。
8. 为 CSV 导入增加预检报告、失败行下载和整批撤销，避免大文件部分成功后需要人工清理。

## P1：业务闭环

1. 完成合作跟进和设计任务拖拽看板，并记录状态变更历史。
2. 补齐商品到视频、视频到达人/商品的双向详情展示，并统一公共 relation 类型。
3. 增加活动日历和发布时间线，统一显示北京时间与站点当地时间。
4. 实现总览指标的日期范围、站点和币种筛选，明确汇率口径。
5. 扩展通知中心：到期任务、待审核素材和合作跟进提醒，并增加通知偏好设置。
6. 增加数据导入/导出和批量校验，方便从现有表格迁移。
7. 接入飞瓜、新榜或未来微信开放能力时，只实现 `ExternalDataSource` 适配器和 PocketBase 定时写入，不改选题库前端。
8. 将爆款标题高频词从标点分词升级为可配置中文分词词典，并保留 SQL 聚合结果作为看板数据源。

## P2：稳定性与交付

1. 建立 GitHub Actions：typecheck、lint、测试、Vite build、macOS DMG、Windows NSIS。
2. 增加 PocketBase 自动备份、恢复演练、迁移前快照和健康监控。
3. 为登录账号枚举 hook 增加网关限流、IP 白名单和审计。
4. 增加 Playwright 端到端测试与桌面窗口截图回归。
5. 增加错误监控，但严格过滤 token、密码、邮箱和业务敏感字段。
6. 评估 PocketBase 高可用和文件对象存储方案，再决定是否把 PB 随桌面端分发。
