# 真实业务数据验收清单

> 适用：本地 Supabase 运行环境（`pnpm supabase:start`）与真实业务数据录入验收。
> 前置：`pnpm supabase:reset && pnpm supabase:test && pnpm supabase:types` 全过；`pnpm dev` 启动 Web。

## 0. 启动与账号

```bash
pnpm supabase:start
pnpm dev
```

使用已注册的五角色账号登录（磊哥 boss / 董雨辰 business / 韩素云 market / 孙铭泽 design / 谢洁 editing）。测试成员杨振康账号用于 business 并发验证；密码见本地会话记录，不写入仓库。
