# 动态玻璃观测舱前端首批改造

## 目标

让 TK观察从通用后台卡片布局收敛为面向高频运营工作的动态玻璃观测界面：玻璃用于导航和状态层，数据表格与操作表单保持清晰、克制和高密度。

## 本批已落地

- 全局应用壳：悬浮玻璃顶栏、受控深空背景、侧边栏观测光带、移动端保留现有汉堡抽屉。
- 总览：增加“核心指标 / 走势与动态 / 运营状态”客户端锚点导航，点击平滑滚动且用 `aria-current` 标识当前位置。
- 通用组件：新增 `Cascader`，用于活动到阶段到任务等明确父子层级选择；叶子节点返回完整 value path。
- 日期选择：继续复用已有 `DatePicker` 与 `Calendar`，后续日期、日期范围和截止时间不以手写文本输入替代。
- 动效：背景光晕和观测扫描线支持 `prefers-reduced-motion`，不添加粒子、全屏光球或无业务含义的动画。

## 使用约束

- 无层级关系的枚举继续使用 `Select`，不要滥用 `Cascader`。
- 客户端长页面和详情页优先使用 `AnchorNavigation`；锚点 section 加 `scroll-mt-24`，避免被悬浮顶栏遮挡。
- 移动端侧栏只使用 `Sidebar` 内建的 `Sheet` 汉堡抽屉，不新增第二套导航抽屉。
- `glass-card` 用于概览、抽屉、筛选和状态区；密集表格及长表单优先使用 `solid-card` 或无卡片分区。

## 后续范围

1. 商务工作台：主表格 + 右侧详情抽屉 + 统一工具栏。
2. 市场/设计/剪辑详情页：按内容区补锚点导航。
3. 具体层级表单：在活动阶段任务、客户关联记录等场景接入 `Cascader`。
4. 日期范围和双时区任务：在需要时扩展 `DatePicker`，不新增平行日期控件。
