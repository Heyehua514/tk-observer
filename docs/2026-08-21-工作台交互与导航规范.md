# TK观察工作台交互与导航规范

## 目的

统一工作台的复杂表单、长页面和移动端操作方式，减少同一类操作在不同模块中使用不同控件的情况。此规范适用于总览、商务、市场、设计、剪辑和后续每日情报中心。

## 1. 页面层级与锚点导航

使用锚点导航的页面：

| 页面类型 | 锚点建议 |
|---|---|
| 总览长页面 | 核心指标、走势与动态、运营状态、今日情报 |
| 商机/客户详情 | 概览、跟进记录、关联信息、状态历史 |
| 活动详情 | 概览、任务看板、招商、报名、财务、进度 |
| 设计需求详情 | 需求说明、视觉参考、交付记录、审核记录 |
| 剪辑详情 | 选题信息、数据表现、分析结论、发布排期 |
| 每日情报详情 | 事实摘要、来源、趋势变化、关联任务 |

规则：

- 锚点使用稳定英文 id，展示文字使用中文。
- 当前锚点必须以 `aria-current="location"` 标记。
- 点击锚点不丢失搜索、筛选、排序和列表位置。
- 宽屏可使用紧凑横向锚点栏；手机端允许横向滚动，但不换成多行挤压按钮。
- 每个锚点区域有清晰标题和 `scroll-margin`，避免被固定顶栏遮挡。

## 2. 层级选择使用 Cascader

以下场景必须优先使用 Cascader：

- 活动 → 阶段 → 任务。
- 工作台 → 模块 → 具体记录。
- 国家/站点 → 类目 → 子类目。
- 来源类型 → 来源名称 → 子频道。
- 每日情报主题 → 子主题 → 行动方向。

规则：

- 叶子节点返回完整路径，而非只返回最后一个值。
- 只有一层且选项少于 8 个时使用 Select。
- 多选层级必须明确展示已选路径，并允许逐条移除。
- Cascader 不用于日期、人员、开关或大段文本输入。

## 3. 日期和时间使用 DatePicker

所有日期、日期范围和时间选择统一使用 DatePicker 或 Date Range Picker，不再新增原生 `input[type=date]` 作为业务表单主控件。

| 业务场景 | 允许日期范围 |
|---|---|
| 历史录入、复盘、实际结果 | 默认不允许未来日期 |
| 预计成交日、任务截止日、活动排期、发布日期 | 允许未来日期 |
| 时间线、活动开始/结束时刻 | 日期加时间，并显示时区 |
| 报表筛选 | 日期范围，支持快捷范围：今天、本周、本月、上月 |

规则：

- 存储使用 UTC，展示默认使用 Asia/Shanghai。
- 涉及活动城市时区时，详情同时显示北京时间和活动所在地时间。
- 未知日期显示“未设置”，不使用假日期。
- 日期选择结果保持 `YYYY-MM-DD` 或完整 ISO 时间格式，转换集中在模型层完成。

## 4. 详情页和右侧抽屉

适用：商机、客户、商单、活动资源、设计素材、设计需求、视频、每日情报。

规则：

- 桌面端优先右侧 Sheet 抽屉，最大宽度约 `36rem` 到 `40rem`。
- 手机端使用全宽 Sheet 抽屉。
- 抽屉固定头部显示标题、状态和关键识别信息。
- 正文单独滚动，底部固定保存、提交或主操作。
- 关闭抽屉不得清空列表筛选、页码、排序或滚动上下文。
- 有多个内容区时使用锚点导航，不额外套一层卡片。
- 关联记录点击后应定位或打开目标记录，不返回静态文本。

## 5. 列表工具栏

适用：客户、达人、商机、商单、活动、场地、素材、选题、情报等高频列表。

规则：

- 同一行组织结果数量、关键词搜索、筛选、日期范围、批量操作和主操作。
- 搜索和筛选状态同步 URL，方便刷新和分享。
- 主操作只保留一个，用图标加文字表达明确命令。
- 批量操作在无选择时隐藏或禁用。
- 桌面端保证主识别字段无需横向滚动；手机端将工具栏拆为上下两层。
- 表格和高密度业务列表使用高不透明度背景，玻璃效果只用于导航、摘要和抽屉。

## 6. 移动端规则

- 一级侧栏使用汉堡按钮和 Sheet 抽屉。
- 二级导航在抽屉内分组，当前入口清楚标识。
- 详情、筛选和日期选择不弹出超过屏幕高度且无法滚动的对话框。
- 图标按钮必须有可读的 `aria-label` 和悬浮提示。
- 390px 宽度下不得出现页面横向滚动、文字覆盖或被固定操作栏遮挡。
- `prefers-reduced-motion` 下关闭入场、抽屉和数据更新的非必要动画。

## 7. 视觉边界

- `glass-card` 只用于应用壳、总览摘要、状态区域、浮层和抽屉。
- 表格、表单和大量文本使用清晰的实色业务面板。
- 动效只服务于页面进入、状态变化、保存反馈和拖拽反馈。
- 不添加粒子、大面积模糊光球或纯装饰性动效。
- 圆角保持克制，常规业务卡片不超过 8px，抽屉和浮层遵循现有组件库。
