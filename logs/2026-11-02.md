## 6. 今日所学

- Supabase CLI 在 Agent 环境中默认走 JSON/非交互模式，`supabase login` 必须加 `--agent no` 才能完成浏览器授权码流程。
- 部署 Edge Function 不需要 Docker；Docker 仅影响本地 Supabase runtime 与 pgTAP 实跑。
- 深链页面的 Tab 必须用深链参数做初始值，不能只靠派生 `activeTab`；否则清除参数的那一刻用户会被弹回默认 Tab。
- 删除 `auth.users` 前必须先删 `public.profiles`，否则外键 `profiles_id_fkey` 会以 `23503` 阻断删除。
